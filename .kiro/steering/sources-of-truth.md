# Research Sources Rule (CCAR-F prep)

When searching the web for learning material, exam content, or technical facts about Claude, the Claude API, the Claude Agent SDK, Claude Code, or MCP:

1. Anthropic is the source of truth. Check these first, in this order:
   - Anthropic Academy on Skilljar: https://anthropic.skilljar.com (courses, practice tests, certification prep)
   - Claude Code docs: https://code.claude.com/docs
   - Claude Developer Platform / API docs: https://platform.claude.com/docs (formerly docs.anthropic.com)
   - Anthropic Engineering blog and research: https://www.anthropic.com/engineering, https://www.anthropic.com/research
   - Model Context Protocol spec: https://modelcontextprotocol.io
   - The official CCAR-F Exam Guide (current version)
2. Use only recent material. Prefer the latest published documentation and whitepapers; discard or flag anything that appears outdated relative to current docs (e.g., renamed tools, deprecated flags, superseded APIs).
3. Third-party sources (blogs, GitHub study guides, Medium, prep sites) are secondary. Use them only to find leads, and verify every fact against Anthropic documentation before using it in lessons or exam questions.
4. When the exam guide and current docs differ (e.g., a tool was renamed), teach the current behavior and explicitly note the exam guide's terminology so both are recognized on test day.
5. Cite the Anthropic source URL for facts used in study material where practical.
